Everything between a link and the main menu.

The parts of a launcher you use every session, in one quiet window.

Link import

Paste, drag in, or clipboard-paste a Modrinth or CurseForge link. Blocklight works out the platform, content type and version, checks it against your instance, resolves dependencies and installs it.

Instances

Keep each pack or version in its own instance, with its own mods, resource packs, shaders and worlds. Set custom JVM arguments per instance.

Offline mode

Blocklight notices when you lose your connection and keeps working. Manage content and launch with a local profile, no Microsoft account required.

Microsoft sign-in

Device-code login through Xbox and Minecraft Services, with a real ownership check. Accounts without Minecraft are refused.

Skins

Change your current account's skin by uploading a PNG or pasting a SkinMC link, right from Settings.

Discord status

An opt-in setting that shows which instance you are playing in your Discord status.

A launch you can watch.

Blocklight prepares the game, then streams its progress and log into the app while it starts. It reuses files already on disk and finds a compatible local Java install.

  1. 1Download the gameThe Minecraft client, libraries, and assets, verified as they arrive.
  2. 2Extract nativesPlatform libraries unpacked for your system.
  3. 3Prepare the loaderFabric and Quilt profiles are merged. NeoForge runs its real installer and processor chain.
  4. 4Start and streamJava arguments are built, the game starts, and its log streams into the launch panel.

Build it from source.

Blocklight is open source. You need Node.js 18 or newer, stable Rust, and the Tauri v2 system dependencies for your OS.

Run it locally

git clone https://github.com/CraftGamer9651/blocklight
cd blocklight
npm install
npm run tauri dev

CurseForge links need an API key, set with BLOCKLIGHT_CURSEFORGE_API_KEY or in Settings. Microsoft sign-in needs your own Azure client id in BLOCKLIGHT_MSA_CLIENT_ID. Modrinth works with no setup.
